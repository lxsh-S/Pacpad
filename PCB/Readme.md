# PCB

This pcb and the schematics were made in Kicad(it was my first time using it!)

## Design

- I first went through the default design that the hackpad kit's tutorial shows us
- Then I built on top of it and added another key, LEDs, OLED display and also a rotatory encoder
- I had to reroute the pcb way too many times cuz I was bring in major changes with each design change
- I didnt use matrix for the keys because we are only using 4 keys and ill be using up 4 GPIO pins anyway in the matrix

## Mistakes and Learnings

- The footprints and symbols are the most important thing for designing pcbs!! - I forgot this way too many times :(
- Learnt to use Kicad and also how footprints work and how really does a pcb work, it;s just a normal connection that we can build with a breadboard (but way more harder). Custom printed boards are used so that we can minimize the mess that we'll create traditionally!
