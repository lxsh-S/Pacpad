# Pacpad

*Pacpad* is a 4-key(5 if we also add the switch from the rotatory encoder) macropad with a rotatory encoder, an OLED screen and 2LEDs !!!!!!

I've used the KMK firmware for this macropad as python is way more easier than C.

## firmware fucntions

- Media control(prev track, play/pause, next track) with the SW2, SW3, and SW$ keys respectively
- Volume control with the rotatory encoder(volume up, volume down and mute)
- The SW1 key is binded with the F11 key for fullscreen
